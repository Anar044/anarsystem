Счета бухгалтерии Payroll

Выберите реальные счета из плана счетов SH Server. Smart Horeca не создаёт отдельные фиктивные счета — журнал Payroll использует выбранные ID и типы реальных счетов.

Расходы на оплату труда *

Дебет при начислении зарплаты и дополнительных часов. Счёт должен относиться к расходам / OPEX.

Задолженность перед сотрудниками *

Кредит при начислении; дебет при фактической выплате сотруднику.

Касса *

Кредитуется при отдельной выплате наличными.

Банковские счета Payroll

Можно добавить несколько реальных банковских счетов SH Server. Один отметьте как счёт по умолчанию; при каждой выплате бухгалтер сможет выбрать любой из списка.

Другой способ выплаты

Необязательно. Используется только если в Payroll выбран способ «Другое».

Взносы работодателя

Подготовлено для следующего этапа полного Payroll: отдельный расходный счёт и обязательство по налогам/взносам.

Проводки, которые будут создаваться

Предпросмотр строится по выбранным реальным счетам.

Для CHAIN: если выбран один ресторан, настройка сохраняется для его department code. Если выбраны все рестораны — сохраняется общий профиль «*», который используется как fallback.
