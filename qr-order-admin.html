Управление QR-заказами

Внутренняя логика Smart Horeca: каждый стол имеет собственный QR; в фастфуде используется один QR. Продукты и суммы сверяются с опубликованным меню на сервере.

Тестовое подключение. Тестовый Payriff настраивается в этом окне и включается владельцем отдельно. Гость сможет проверить тестовую оплату, но создание заказа в iikoFront, списание и печать на кухне пока заблокированы.

QR-меню ещё не опубликовано

Опубликуйте QR-меню выбранного тестового ресторана. Только после этого здесь будут доступны кассы, столы и журнал заказов.

Настройка действует только для выбранного ресторана в текущей организации Smart Horeca. Не нужно добавлять отдельные Merchant ID или Secret Key в Cloudflare для каждого ресторана.

Загружаем ресторан…

Secret Key сохраняется на сервере в зашифрованном виде и никогда не показывается повторно. При изменении только других полей его можно оставить пустым.

Проверка реального платежа пока не активирована
Перечисление денег ресторану

Деньги поступают в Payriff Wallet, а банковские реквизиты и вывод средств управляются в Payriff → Applications → ⋯ → Edit withdraw method / Payouts. Smart Horeca пока не меняет банковский счёт в Payriff и не выполняет выплат.

Открыть Payriff для настройки счёта и выплат ↗

Создание заказов в iikoFront и печать кухни останутся заблокированы до полноценной проверки успешной онлайн-оплаты.
