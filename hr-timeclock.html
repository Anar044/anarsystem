Устройства учёта времени
В Push / ADMS терминал сам выходит через интернет на центральный SmartHoreca ZKTeco Gateway. Serial Number определяет, какому устройству принадлежит событие.
Push / ADMS: в самом терминале указываем адрес Public ADMS Gateway и порт. IP терминала сохраняем для диагностики; для маршрутизации через интернет он не нужен. Direct TCP будет включён отдельно после проверки реального F18.

Как работает интеграция

Терминал ZKTeco сам подключается к публичному Gateway и отправляет ATTLOG. Gateway определяет устройство по Serial Number, берёт его индивидуальный SmartHoreca token из защищённого registry, ставит событие в очередь и отправляет в /api/hr/device-ingest. Если SmartHoreca временно недоступен, очередь остаётся на Gateway и повторится автоматически.

ZKTeco→Internet / ADMS→Public Gateway→SN → device token→SmartHoreca→Табель / Payroll
