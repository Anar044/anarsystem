Два способа подключения

1. Компьютер в ресторане: Local Agent получает IP и порт из SmartHoreca, подключается к ZKTeco по TCP/UDP и отправляет новые отметки по HTTPS. 2. Gateway: сам терминал отправляет ATTLOG через интернет на Public ADMS Gateway.
