# SH_Reports — настройка регистрации и входа

В проект добавлена авторизация через Supabase Auth.

## Что уже работает в коде

- вход по Email + пароль;
- регистрация: имя, фамилия, email, телефон, пароль;
- подтверждение email;
- восстановление пароля;
- смена пароля после ссылки восстановления;
- сохранение сессии после обновления страницы;
- автоматический редирект неавторизованного пользователя на страницу входа;
- выход из аккаунта;
- имя пользователя отображается в интерфейсе;
- данные имени, фамилии и телефона сохраняются в user metadata Supabase;
- существующий iiko/OLAP функционал не заменяется авторизацией.

## 1. Создать Supabase project

Создайте проект в Supabase.

## 2. Включить подтверждение email

В Supabase откройте Authentication -> Providers -> Email и убедитесь, что Email provider включён и подтверждение email включено.

Пока email не подтверждён, пользователь не должен получать полноценную сессию после регистрации.

## 3. Настроить URL

В Authentication -> URL Configuration укажите:

Site URL:
https://anarsystem.pages.dev

Redirect URLs:
https://anarsystem.pages.dev/auth-callback.html
https://anarsystem.pages.dev/reset-password.html

При локальной разработке можно добавить соответствующие localhost URL.

## 4. Вставить ключи проекта

Откройте файл:

auth-config.js

Замените:

YOUR_PROJECT.supabase.co
YOUR_SUPABASE_PUBLISHABLE_KEY

на Project URL и Publishable Key из настроек Supabase.

ВАЖНО: service_role / secret key нельзя помещать в браузерный код.

## 5. Email

Для первого тестирования можно использовать стандартный механизм отправки email Supabase. Для production рекомендуется настроить собственный SMTP-провайдер, чтобы письма отправлялись с вашего домена и не зависели от ограничений тестовой почты.

## 6. После публикации

Проверка:

1. Открыть https://anarsystem.pages.dev/
2. Должна появиться страница входа.
3. Нажать «Создать аккаунт».
4. Заполнить имя, фамилию, email, телефон и пароль.
5. Получить письмо.
6. Перейти по ссылке подтверждения.
7. После подтверждения войти.
8. Обновить страницу F5 — авторизация должна сохраниться.
9. Выйти — сайт снова должен требовать вход.
10. Проверить «Забыли пароль?».
